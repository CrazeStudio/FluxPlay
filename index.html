The project

An idea that
became an app.

FluxPlay started as a personal Android project and grew into a full media playback experience.

Instead of trying to become another streaming platform, the project focuses on something simpler: playing your media your way.

This website exists for one reason — to show the project properly.

Inside the build

More than
a play button.

The feature set is built around actual media playback and management rather than filler.

▶

Direct streaming

Play supported HTTP and HTTPS media sources directly inside FluxPlay.

▣

Local playback

Open supported video and audio files stored on the device.

CC

Subtitles

Embedded and external SRT, VTT and ASS/SSA subtitles.

↓

Downloads

Pause, resume, retry and cancel supported media downloads.

↔

Gesture controls

Seek through playback and adjust brightness and volume with gestures. Aspect ratio, orientation and other player controls are available without covering the entire screen.

↗

Picture-in-Picture

Keep compatible playback visible while using other applications.

★

History

Resume playback and keep track of previously played media.

☰

Playlists

Create and organize custom media collections.

◷

Sleep timer

Stop playback automatically after a selected amount of time.

Under the hood

The technical
side of the flex.

The current build uses a modern Android stack with the previous libmpv dependency stack removed.

UI

Kotlin + Jetpack Compose

Modern Android UI architecture with Compose-based screens and components.

Playback

Media3 / ExoPlayer

Android media playback using Media3 and the decoding capabilities available on the device.

Data

Room + StateFlow

Local persistence and reactive state handling for application data.

Architecture

ViewModel + Coroutines

Kotlin-based asynchronous work and structured application state.
